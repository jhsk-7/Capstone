# Capstone
Mobile Bike Cleaning Service Application

In terminal: Go into project folder. Run npm run dev.

In web browser:

For "clients": Go to "http://localhost:3000/signup" to create an account. Go to "http://localhost:3000/login" to access your account. Go to "http://localhost:3000/addBike" to add bikes to your account. Go to "http://localhost:3000/myBikes" to view your bikes. Go to "http://localhost:3000/appointment" to add an appointment. Go to "http://localhost:3000/appointment/myAppointments" to view your appointments.

For "admins": Go to "http://localhost:3000/admin/signup" to create an admin account. Use ADMIN_SIGNUP_CODE for a secret admin signup key. Go to "http://localhost:3000/admin/login" to access admin account. Go to "http://localhost:3000/admin/services" to create services.
